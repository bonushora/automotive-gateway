# Automotive Gateway

Plataforma de diagnostico automotivo multiplataforma.

## Plataformas-alvo
- Linux
- macOS
- Windows
- Android
- iOS

## Desenvolvimento
- Ambiente principal: Linux Mint
- Gateway proposto: ESP32-S3 N16R8
- Aplicativo proposto: Flutter
- Firmware proposto: ESP-IDF

## Governanca
BH-SEP v2.3 / BH-SDP v2.3
